# Reproduction guide

## 1. Environment

Create and activate a Python environment, then install the dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows, activate with:

```powershell
.venv\Scripts\activate
```

## 2. Local data placement

Restricted source files must remain outside version control. Place authorized files in local folders excluded by `.gitignore`, such as:

```text
data/raw/
data/external/
```

The exact filenames and variables must be aligned with the documentation and preprocessing scripts.

## 3. Recommended analytical order

The current final analytical chain is:

```bash
python src/robust_underreporting_v17.py
python src/sensitivity_scenario_factors_v22.py
python src/spatial_access_services_v18.py
python src/pareto_validation_v20.py
python src/electre_tri_b_v25.py
```

Some scripts depend on processed municipal files generated by earlier preprocessing stages. Those stages will be documented and consolidated before the public release is finalized.

## 4. Expected outputs

The final pipeline should reproduce:

- 144 municipalities;
- 216 analytical scenarios;
- factor-level sensitivity summaries;
- territorial-barrier scores;
- Pareto fronts;
- 108 ELECTRE TRI-B sensitivity specifications;
- baseline ELECTRE distribution of 91 Low, 27 Moderate, 16 High, and 10 Very high priority municipalities.

## 5. Interpretation

Outputs are screening and decision-support results. They do not prove underreporting or estimate the true number of unreported cases.
