# Territorial barrier calculation

## Analytical role

The territorial barrier is not included in the flag generated by the 216 scenarios. The scenario signal is based on institutional fragility and persistently low reporting visibility. Territorial accessibility is evaluated afterward to qualify investigation priority and support the consolidated principal and expanded groups.

## Geographic source

The current implementation reads municipal geometries from:

```text
data/raw/munics.geojson
```

The file is expected to contain IBGE municipal codes in `codarea` and valid municipal polygon or multipolygon geometries. The public-release documentation should identify the exact IBGE geographic product, reference year, download date and source URL when confirmed.

## Representative municipal point

For each municipality, the code uses GeoPandas `geometry.representative_point()`.

This returns a point guaranteed to lie within the municipal geometry. It is not necessarily the municipal headquarters, population centroid, road-network centroid or service-demand centre.

## Geodesic distance

Distances are calculated with `pyproj.Geod` using the WGS84 ellipsoid:

```python
GEOD = Geod(ellps='WGS84')
_, _, distance_m = GEOD.inv(lon1, lat1, lon2, lat2)
distance_km = distance_m / 1000
```

The output unit is kilometres.

This is an ellipsoidal geodesic distance between representative municipal points. It does not represent road distance, river-route distance, transport availability, seasonality, cost or actual travel time.

## Service sets

### Any specialized service

A municipality belongs to this hub set when it contains at least one of:

- `casa_abrigo`;
- `ceam_niam`;
- `servico_violencia_sexual`;
- `centro_integrado`;
- `unidade_movel`;
- `casa_passagem`.

### High-complexity service

A municipality belongs to this hub set when it contains at least one of:

- `casa_abrigo`;
- `ceam_niam`;
- `centro_integrado`;
- `casa_passagem`.

The distinction is operational and should be described as a study definition rather than a universal classification unless it is explicitly grounded in an external normative source.

## Nearest-hub calculation

For each municipality and service set, the script calculates the distance to every eligible hub and retains the minimum geodesic distance.

The output also stores the IBGE code and name of the nearest hub.

## Municipalities with their own service

A municipality that belongs to a service hub set is compared with its own representative point. Its minimum distance for that service set is therefore zero kilometres.

This treatment encodes the existence of a service within the municipality, but does not capture the internal distance from residents to the service facility or whether the service is continuously operational.

## Normalization

Each distance measure is converted into an empirical percentile rank across the 144 municipalities:

```text
percentile_distance = average_rank(distance) / number_of_municipalities × 100
```

Tied distances receive average ranks.

Higher percentiles indicate greater geographic separation from the corresponding service set.

## Final score

The territorial barrier score is:

```text
territorial_barrier =
    0.45 × percentile_distance_to_any_specialized_service
  + 0.55 × percentile_distance_to_high_complexity_service
```

The score is expressed on an approximate 0–100 percentile-based scale.

## Descriptive classes

| Score interval | Class |
|---|---|
| up to 20 | Very low |
| above 20 to 40 | Low |
| above 40 to 60 | Medium |
| above 60 to 80 | High |
| above 80 | Very high |

These classes are descriptive. Alternative cut points may be explored only as a separate sensitivity analysis because changing them could affect the composition of the principal and expanded groups.

## Known limitations

- a representative polygon point is not the municipal headquarters;
- geodesic distance is not travel time;
- Amazonian mobility often depends on river routes, seasonal conditions and multimodal transport;
- municipal service presence does not guarantee availability, capacity, quality or accessibility;
- mobile services are coded as municipal service presence even though their spatial reach may differ from fixed facilities;
- within-municipality spatial inequality is not measured;
- the two service sets overlap by design.
