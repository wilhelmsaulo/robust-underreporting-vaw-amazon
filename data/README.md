# Data directory

This repository does not redistribute raw police microdata or other files that may be subject to institutional, legal, or privacy restrictions.

## Source data used in the study

- MUNIC 2023 institutional indicators;
- SEGUP/CODEC police records for 2022–2025;
- 2022 Census female population;
- municipal geographic data and service locations.

## Included materials

Only non-identifying derived outputs, model configurations, and documentation approved for public dissemination should be stored here.

## Restricted materials

The following paths are excluded by `.gitignore` and must not be committed:

- `data/raw/`
- `data/external/`
- `private/`

Researchers seeking to reproduce the complete pipeline must obtain the restricted source files directly from the corresponding data providers and place them locally according to the reproduction guide.
